Dreamplay1 GitHub Pages files

1. Upload index.html to the ROOT of your GitHub repository.
2. Do not upload it inside another nested folder such as /html or /website.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select your publishing branch (usually main) and folder /(root), then Save.
6. Wait for GitHub Pages to finish deploying, then open the published URL.

The supplied page is self-contained: its CSS, JavaScript and logo are embedded in index.html.
The homepage must be named exactly: index.html (lowercase).
